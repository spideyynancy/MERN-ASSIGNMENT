Understanding the CSS Box Model

Learn how spacing and dimensions work in CSS.

1. What is the CSS Box Model?

The CSS Box Model explains how every HTML element is represented as a rectangular box on a webpage. It consists of content, padding, border and margin.

2. Box Model Demonstration

The following example shows the different layers of the CSS Box Model.

Margin: Space outside the border
Border: Edge surrounding the padding
Padding: Space inside the border
CONTENT
Actual text or element content

3. CSS Code Example

.example {
    width: 300px;
    padding: 20px;
    border: 5px solid purple;
    margin: 25px;
    background-color: lightgreen;
}

The CSS properties above control the content width, inner spacing, border thickness and outer spacing.

4. Box Model Properties

Property Purpose
Content Contains text, images or other elements.
Padding Creates space between content and border.
Border Surrounds the padding and content.
Margin Creates space outside the border.
Box-sizing Controls how an element's width and height are calculated.

5. Why is the Box Model Important?

The Box Model helps developers control element size, spacing and alignment. Understanding it makes website layouts easier to create and maintain.
