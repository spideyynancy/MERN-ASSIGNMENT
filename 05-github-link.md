steps for creating new repo on github are as follows:
Open [GitHub](https://github.com) and log in to your account
Click on the **+ icon** in the top-right corner and select New repository
Enter your repository name, such as `my-first-project`, and add a description if required
 Choose Public or Private according to your preference
 Tick the Add a README file option if you want to create a README file
Click on the green Create repository button. Your new repository is now ready then make a folder and add open it in vs code
